# Demo script

Aim for about 1 minute 45 seconds. Record the browser at 10:45 on the quiet morning, with no Ring token and no model key, unless you want the last beat to show a live Grok note.

| Time | On screen | Say |
| --- | --- | --- |
| 0:00 | Today, feed banner and the letter | "This is Caretaker Check-in, for someone looking after a relative who lives alone. The feed is simulated and labeled. It is door and motion metadata, never video." |
| 0:18 | Scroll the note and a citation chip | "Grok writes this when a key is set. Each line has to point at an event. If the model diagnoses or calls it an emergency, the verifier throws that draft away and the template says the same facts." |
| 0:38 | The waiting check-in | "It's past 9:30 and the morning was quiet, so the watch drafted a hello. It is waiting. Nothing has been sent." |
| 0:52 | Check-ins, hover Approve, do not imply send | "I can approve the wording or copy it to my own phone. There is no send button." |
| 1:05 | Companion, ask how the morning compares, show the trace | "The companion is the published agent network, running in the browser. It called the routine reader, and the reader called this page's tool." |
| 1:22 | Health panel | "If Ring times out, or the token expires, or Grok is absent, the page says so and falls back. The day stays readable." |
| 1:35 | Settings, simulated day switch, or the token field | "A Playground token syncs real metadata the same way. The demo does not need one." |
| 1:45 | Back on the note | "The agent may notice. The person still decides." |

Stop before 2:00. If a key is configured, add one sentence at 0:18: "This wording came back from Grok, and search was left off."
